## Purpose:

The Data Mining project involves the application of data mining techniques discussed in class or in
readings to one or more specific data sets. The goal of this project is to go through the full data mining
cycle with respect to a particular data set (including the specification of the business problem to be
solved, the specification of the data mining tasks to be performed, selection, preprocessing, integration,
and transformation of the data, application of several data mining tasks and the discovery of patterns,
evaluation of patterns, and recommending specific actions with respect to relevant findings). A project
may involve the application of data mining in a particular domain and data set with which you are
familiar such as your work, the Web, e-commerce, etc. The final presentation should include a detailed
analysis of the complete scenario for the application of the data mining process, including specification
of the data mining problem (based on application objectives), data collection, data preparation, pattern
discovery using a variety of data mining and statistical techniques, interpretation of results, and
conclusions.

## Approach

The class will be divided into teams, where a team consists of three to four students. Each team will
build a complete data mining analysis of a dataset by the end of the term. This analysis has been divided
into four assignments where each assignment builds on the work performed in prior assignments,
culminating in a complete analysis by the end of the semester. Each assignment will be presented in
class by all team members; each team members must participation in presentation. Assignments must
be uploaded to Brightspace by midnight of the specified due date. Typically, all team members will
receive the same grade for each assignment, however the professor reserves the right to adjust
individual grades. Team members must be identified in their proposal and work as a team throughout
the project. Non-participation is an automatic failure

## Assignments

The project has been segmented into four assignments. Each assignment corrects mistakes in prior
assignment and adds new content according to assignment description. The final assignment must
contain all content from prior assignments and delivered as a cogent story. Each assignment must
be submitted any time prior to its assigned deadline. The first three assignments are worth 20% of final
grade and the final assignment is worth 40%. Late assignments will be assessed a 20% penalty.
Assignment will be presented in class and include a Q&A session. Students are expected to ask
constructive and insightful questions. Teams must correct assignment per feedback after each
presentation and final presentation must include all corrections. Grading will be based on organization,
content, evidence of analysis, presentation quality and quality of answers during Q&A session. I
recommend that you start working on this early and not wait until the last minute.
